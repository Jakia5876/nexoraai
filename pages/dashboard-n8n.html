HTTP Request Node Configuration

In your n8n workflow, use an HTTP Request node to send the reply back to WhatsApp:

{
  "method": "POST",
  "url": "https://api.nexoraai.com/v1/messages/send",
  "authentication": "genericCredentialType",
  "genericAuthType": "httpHeaderAuth",
  "headers": {
    "Authorization": "Bearer nex_live_YOUR_API_KEY",
    "Content-Type": "application/json"
  },
  "body": {
    "to": "={{ $json.sender }}",
    "type": "text",
    "message": "={{ $json.ai_generated_reply }}"
  }
}
