NEXORAAI Developer Quickstart

The NEXORAAI REST API enables you to programmatically send WhatsApp messages, configure AI chatbot behaviors, query CRM contacts, and stream real-time webhook events into your own servers.

Authentication

All API requests must include your Bearer token in the Authorization HTTP header. Retrieve your key from the API & Keys Dashboard.

Authorization: Bearer nex_live_9482bf7a8e2394017e8c11aa5544
POST /v1/messages/send

Send an instant WhatsApp message to a recipient in E.164 phone format (e.g. +8801712345678).

Request Payload (JSON)

{ "to": "+8801712345678", "type": "text", "message": "Your order #WA-9482 has been shipped via Pathao Courier!", "ai_autopilot": false }

Response (200 OK)

{ "status": "success", "message_id": "msg_8492019482", "recipient": "+8801712345678", "dispatched_at": "2026-10-04T12:50:00Z" }
WEBHOOK SPECIFICATION

Event: message.received

Dispatched in real-time when an incoming message is received on any connected WhatsApp number.
