Module 1: Getting Started with NEXORAAI (দ্রুত শুরু ও অ্যাকাউন্ট সেটআপ)

Basic workspace onboarding, business profile, and platform navigation

GETTING STARTED

NEXORAAI-তে আপনাকে স্বাগতম! আপনার ব্যবসা শুরু করতে নিচের ৪টি সহজ ধাপ সম্পন্ন করুন:

1 ব্যবসার প্রোফাইল কনফিগারেশন
Settings পেজে গিয়ে আপনার শপ/ব্যবসার নাম, অফিশিয়াল ইমেইল, মুদ্রা (BDT / USD), এবং টাইমজোন (Asia/Dhaka) সিলেক্ট করুন।
2 হোয়াটসঅ্যাপ নম্বর যুক্ত করা
WhatsApp Gateway পেজে গিয়ে আপনার ফোন দিয়ে কিউআর কোড (QR Code) স্ক্যান করুন।
3 প্রোডাক্ট বা নলেজ বেস ডকুমেন্ট আপলোড
Knowledge Base পেজে আপনার পণ্যের তালিকা, মূল্য এবং সাধারণ প্রশ্নোত্তর (FAQ) সমৃদ্ধ PDF বা টেক্সট ফাইল আপলোড করুন।
💡
প্রো-টিপ: আপনি যদি সম্পূর্ণ সেটআপটি ধাপে ধাপে গাইড হিসেবে দেখতে চান, তবে আমাদের ইন্টারেক্টিভ Setup Wizard রান করতে পারেন।
📱

Module 2: WhatsApp Setup & Connection (হোয়াটসঅ্যাপ সংযোগ পদ্ধতি)

QR Code Web Gateway and Official Meta WhatsApp Cloud API connection methods

WHATSAPP
পদ্ধতি ক: QR Code Gateway (সবচেয়ে সহজ)
  1. আপনার মোবাইল থেকে WhatsApp ওপেন করুন।
  2. উপরে ৩-ডটে ট্যাপ করে Linked Devices সিলেক্ট করুন।
  3. Link a device চাপুন এবং ড্যাশবোর্ডে প্রদর্শিত QR Code স্ক্যান করুন।
  4. কানেক্ট হওয়ার সাথে সাথে আপনার স্ট্যাটাস Connected দেখাবে।
পদ্ধতি খ: Official Meta Cloud API
  1. Meta for Developers একাউন্ট থেকে WhatsApp Business Cloud API চালু করুন।
  2. আপনার Phone Number ID এবং Permanent Access Token কপি করুন।
  3. ড্যাশবোর্ডের Meta API Setup ফিল্ডে পেস্ট করে Save করুন।
  4. অফিশিয়াল গ্রিন টিক ও আনলিমিটেড ভলিউম ক্যাম্পেইনের জন্য এটি আদর্শ।
⚠️
অ্যান্টি-ব্যান নিয়ম (Anti-Ban Warming Policy): নতুন নম্বরে প্রথম দিনেই একসাথে হাজার হাজার অপরিচিত কাস্টমারকে মেসেজ পাঠাবেন না! দিনে ৩০-৫০ জন দিয়ে শুরু করুন এবং প্রতি মেসেজের মাঝে ২ থেকে ৪ সেকেন্ড বিরতি রাখুন।
🤖

Module 3: AI Agents & Knowledge Base (এআই সাপোর্ট এজেন্ট ও নলেজ বেস)

Train GPT-4o, Claude & Gemini on your shop FAQ and product information

AI AGENT
১. প্রোডাক্ট তথ্য ও FAQ ফাইল আপলোড

Knowledge Base পেজে যান। আপনার ডেলিভারি চার্জ (যেমন: ঢাকার ভেতর ৬০৳, বাইরে ১২০৳), রিটার্ন পলিসি, সাইজ চার্ট, এবং অফার সম্বলিত PDF, Word বা টেক্সট ফাইল ড্রপ করুন। আমাদের ব্যাকএন্ড স্বয়ংক্রিয়ভাবে এটি এআই ভেক্টর ডাটাবেজে যুক্ত করবে।

২. এআই এজেন্টের প্রম্পট ও কথা বলার ধরন নির্ধারণ

AI Agents পেজে গিয়ে এজেন্টের ব্যক্তিত্ব সিলেক্ট করুন: "Professional & Courteous (মার্জিত ও পেশাদার)" অথবা "Friendly Bengali Sales Representative"।

// এজেন্টের জন্য সেরা সিস্টেম প্রম্পট উদাহরণ: "আপনি একজন অভিজ্ঞ সেলস অ্যাসিস্ট্যান্ট। সর্বদা মার্জিত ভাষায় বাংলায় কাস্টমারকে সালাম জানিয়ে উত্তর দিবেন। নলেজ বেসের বাইরে কোনো মনগড়া দাম বলবেন না। কোনো তথ্য না জানা থাকলে বলবেন: 'আমাদের প্রতিনিধি শীঘ্রই আপনার সাথে যোগাযোগ করবেন'।"
৩. হিউম্যান হ্যান্ডঅফ (Human Handoff)

কাস্টমার যদি জটিল কোনো সমস্যা নিয়ে কথা বলতে চায় বা "agent" / "কথা বলতে চাই" লিখে, তখন এআই স্বয়ংক্রিয়ভাবে কথোপকথন হোল্ড করে মানুষের কাছে নোটিফিকেশন পাঠিয়ে দেবে।

Module 4: Automations & Keyword Triggers (চ্যাটবট ও কিওয়ার্ড অটোমেশন)

Instant greetings, off-hours replies, and keyword auto-responses

AUTOMATIONS
👋 Welcome Greeting
যেকোনো কাস্টমার প্রথমবার মেসেজ দিলে সাথে সাথে স্বাগতম বার্তা ও প্রধান মেনু অপশন পাঠাবে।
🌙 Out-of-Hours Auto Reply
রাত ১০টার পর মেসেজ আসলে জানিয়ে দেবে: "আমাদের অফিস সকাল ৯টায় খুলবে। আপনার মেসেজ পেয়েছি।"
🔑 Keyword Triggers
কাস্টমার 'দাম', 'price', 'order', 'address' ইত্যাদি লিখলে পূর্বনির্ধারিত উত্তর চলে যাবে।

Module 5: Incomplete Orders & Cart Recovery (পরিত্যক্ত চেকআউট রিকভারি)

Recover dropped e-commerce orders on WhatsApp with 1-click checkout confirmation

CART RECOVERY

অনলাইন শপের প্রায় ৬০-৭০% ক্রেতা চেকআউট পেজে নাম ও নম্বর দেওয়ার পর পেমেন্ট না করে বা অর্ডার কনফার্ম না করে পেইজ বন্ধ করে দেয়। NEXORAAI এই ক্রেতাদের স্বয়ংক্রিয়ভাবে রিকভার করে:

১. WooCommerce বা কাস্টম ওয়েবসাইটে ট্র্যাকার প্লাগইন বসানো

আপনার চেকআউট পেজের </body> ট্যাগের ঠিক আগে নিচের স্ক্রিপ্টটি বসিয়ে দিন:

<script src="https://nexoraai.com/assets/js/iot-checkout.js" data-store="YOUR_STORE_NAME" data-webhook="https://nexoraai.com/api/webhooks/orders"></script>
২. হোয়াটসঅ্যাপে ১-ক্লিকে রিকভারি পাঠানো

Incomplete Orders পেজে গিয়ে যেসকল ক্রেতা চেকআউটে আটকে রয়েছে তাদের নামের পাশে থাকা "Send WhatsApp Recovery" বাটনে ক্লিক করলেই প্রি-ফিল্ড অফার ও কনফার্মেশন লিংক সহ মেসেজ চলে যাবে।

Module 6: WhatsApp Bulk SMS & Email Blaster (বাল্ক মেসেজিং ও মার্কেটিং)

Send targeted promotional campaigns without getting banned

MARKETING
📱 WhatsApp Bulk SMS

Broadcasts পেজে কাস্টমারদের ফোন নম্বর CSV ফরম্যাটে আপলোড করুন। মেসেজে {{name}} ট্যাগ ব্যবহার করুন যাতে প্রতিটি ক্রেতা তার নাম দিয়ে মেসেজ পায়।

📧 Bulk Email Blaster

Email Blaster পেজে আপনার জিমেইল/এসএমটিপি (SMTP) কানেক্ট করে আকর্ষণীয় নিউজলেটার ও অফার ইমেইল পাঠাতে পারবেন।

Module 7: Contacts & Sales Pipeline CRM (কন্টাক্টস ও সেলস পাইপলাইন)

Manage customer tags, segment lists, and track sales deals

CRM

আপনার সমস্ত কাস্টমার ডাটাবেজ এক ছাতার নিচে গুছিয়ে রাখুন:

  • ট্যাগিং (Tags): কাস্টমারদের "VIP", "Wholesale", "New Lead", "Repeat Buyer" ইত্যাদি ট্যাগে সাজান।
  • কানবান পাইপলাইন (Kanban Pipeline): Leads পেজে কাস্টমারকে এক স্টেজ থেকে অন্য স্টেজে (Lead → Contacted → Order Placed → Won) ড্র্যাগ-অ্যান্ড-ড্রপ করে ট্র্যাকিং করুন।
  • অমনিচ্যানেল ইনবক্স: Inbox পেজে একই উইন্ডোতে সব কাস্টমারের সাথে লাইভ চ্যাট করুন।
🔌

Module 8: Webhooks, E-Commerce & n8n Integration (ইন্টিগ্রেশন গাইড)

Connect WooCommerce, Shopify, n8n workflows, Google Sheets, and custom API

INTEGRATIONS
১. এপিআই কি (API Key) সংগ্রহ

API & Keys পেজে গিয়ে Generate New API Key চাপুন এবং আপনার সুরক্ষিত কি সংরক্ষণ করুন।

২. আউটবাউন্ড ওয়েবহুক (Webhooks)

Webhooks পেজে আপনার n8n বা Zapier এন্ডপয়েন্ট ইউআরএল দিন। মেসেজ আসলে বা নতুন লিড যুক্ত হলে সাথে সাথে সেখানে ডাটা পোস্ট হয়ে যাবে।

💬 কোনো বিষয়ে সাহায্য প্রয়োজন?
