1. Platform Architecture & Technical Ecosystem (সিস্টেম আর্কিটেকচার)

Core multi-tenant SaaS components, database structure, and integration boundaries

INFRASTRUCTURE

NEXORAAI একটি আধুনিক মাল্টি-টেন্যান্ট (Multi-Tenant) আর্কিটেকচারের উপর নির্মিত। প্রতিটি ব্যবসায়ী নিজস্ব আইসোলেটেড ওয়ার্কস্পেস, কাস্টমার ডাটা, হোয়াটসঅ্যাপ সেশন এবং কাস্টম নলেজ বেস পরিচালনা করতে পারে।

🌐 Frontend Layer
HTML5 + ভ্যানিলা সিএসএস টোকেন সিস্টেম। রেসপন্সিভ ৩-কলাম অমনিচ্যানেল ইনবক্স, গ্লোবাল কমান্ড প্যালেট (Ctrl + K) এবং ডুয়েল ল্যাঙ্গুয়েজ সাপোর্ট।
🗄️ Database & Cloud Backend
Supabase (PostgreSQL 15)। ২৪টি টেবিলের প্রতিটিতে Row Level Security (RLS) কার্যকর। রিয়েলটাইম ওয়েবসকেট ব্রডকাস্ট এবং এজ ফাংশনস।
🧠 Conversational AI Engine
Hybrid GPT-4o, Claude 3.5 Sonnet, এবং Gemini। কাস্টমার নলেজ ডকুমেন্ট থেকে pgvector এমবেডিংসের মাধ্যমে নিখুঁত তথ্যে জবাব দেয়।
⚡ WhatsApp & Automations
Meta Cloud API (v20.0+) এবং n8n ওয়ার্কফ্লো ইঞ্জিন। রিয়েল-টাইম ওয়েবহুক ইভেন্টস, রেট লিমিট বাফার ও অটো রি-ট্রাই।

2. Super Admin Daily Operating Procedures (SOP - দৈনন্দিন রুটিন)

Hour-by-hour operational checklist for maintaining platform health and client SLAs

ADMIN SOP
1 সকাল ০৯:০০ — সিস্টেম হেলথ ও সকেট ডায়াগনস্টিক
হোয়াটসঅ্যাপ কানেকশন স্ট্যাটাস Connected এবং কোয়ালিটি Green (High) আছে কিনা যাচাই করুন। ওয়েবহুক লেটেন্সি < 450ms নিশ্চিত করুন।
2 দুপুর ০২:০০ — টেন্যান্ট অনবোর্ডিং ও কেওয়াইসি যাচাই
নতুন ব্যবসার ডোমেইন ও ফোন নম্বরের মালিকানা সত্যতা যাচাই করুন। ব্রডকাস্ট ক্যাম্পেইন অডিট করে স্প্যাম মুক্ত রাখুন।
3 রাত ০৮:০০ — অর্ডার রিকভারি ও রিভিনিউ অডিট
দৈনিক কতগুলো ইনকমপ্লিট অর্ডার হোয়াটসঅ্যাপের মাধ্যমে রিকভার হয়েছে এবং অর্জিত GMV (৳) হিসাব করুন।
4 রাত ১১:৩০ — সিকিউরিটি অডিট ও ব্যাকআপ ভেরিফিকেশন
audit_logs টেবিলে অস্বাভাবিক অ্যাক্সেস নেই তা নিশ্চিত করুন এবং অটোমেটেড স্ন্যাপশট ব্যাকআপ ভেরিফাই করুন।
