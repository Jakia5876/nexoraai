⚡ Incomplete Orders Tracker Integration

Add this JavaScript snippet to your website/WooCommerce checkout to automatically capture names, phone numbers, and cart items as customers type:

1. Frontend JavaScript Embed (iot-checkout.js) 
<script src="https://nexoraai.com/assets/js/iot-checkout.js" data-tenant-key="ORG_NEXORA_LIVE" data-endpoint="https://api.nexoraai.com/v1/track/incomplete" defer></script>
2. WooCommerce / WordPress Plugin (incomplete-orders-tracker.php) 
<?php
// Place in wp-content/plugins/incomplete-orders-tracker/
add_action('wp_footer', function() {
    if (is_checkout()) {
        echo '<script src="' . plugin_dir_url(__FILE__) . 'assets/iot-checkout.js"></script>';
    }
});
?>
