⚡ Incomplete Orders Tracker Integration

Capture checkout inputs (Name, Phone number, Email, Address, Selected Products) in real-time as the customer types. If they close the tab or disconnect before placing the order, their session is automatically pushed to this tracker.

Option 1: Frontend JavaScript Embed (iot-checkout.js) 
<!-- NEXORAAI Incomplete Orders Realtime Tracker -->
<script src="https://nexoraai.com/assets/js/iot-checkout.js" data-tenant-key="ORG_NEXORA_LIVE" data-endpoint="https://api.nexoraai.com/v1/track/incomplete" defer></script>
Option 2: WordPress / WooCommerce Plugin (incomplete-orders-tracker.php) 
<?php
// In WooCommerce functions.php or mu-plugins:
add_action('wp_footer', function() {
    if (is_checkout()) {
        echo '<script src="' . plugin_dir_url(__FILE__) . 'assets/iot-checkout.js"></script>';
    }
});
?>
