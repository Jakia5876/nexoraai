NEXORAAI REST API

The NEXORAAI API empowers developers to automate WhatsApp communications, synchronize CRM pipelines, trigger AI conversational agents, and build custom multi-channel workflows using standard REST protocols.

Root Endpoint URL
https://api.nexoraai.com/v1

Authentication

All requests must include your organization's API Secret Key passed via the Authorization bearer header. You can generate and rotate API keys from the API & Keys Dashboard.

Authorization: Bearer nx_live_948f92b7194ec8942a10
POST /messages/text

Send Text Message

Dispatches a standard text WhatsApp message to a destination phone number via your connected session.

Request Body

FieldTypeRequiredDescription
session_id string Yes UUID of the active WhatsApp session.
to string Yes Recipient phone number in E.164 format (e.g. +8801700000000).
message string Yes UTF-8 text content (up to 4096 characters).
ai_context boolean No If true, records message into conversation context for AI responders.
POST /messages/media

Send Media Message

Sends an image, video, audio voice note, or PDF document with an optional caption.

Request Body

FieldTypeRequiredDescription
session_id string Yes UUID of the sending session.
to string Yes E.164 phone number.
media_type string Yes image, video, audio, or document.
media_url string Yes Public HTTPS URL or Supabase Storage signed asset URL.
caption string No Accompanying text caption.
GET /sessions

List WhatsApp Sessions

Returns all active, connecting, and disconnected WhatsApp instances for the authenticated organization.

Webhook Event Subscriptions

Subscribe your HTTP endpoint to receive realtime updates when inbound WhatsApp messages arrive, delivery receipts change, or new leads are converted.

Event NameTrigger Description
message.receivedIncoming customer message from WhatsApp.
message.deliveredRecipient phone received outbound message.
message.readBlue checkmark read receipt confirmed.
lead.createdAI agent or automation captured a verified lead.
session.disconnectedWhatsApp instance disconnected or QR expired.

Error Codes

NEXORAAI returns standard HTTP status codes. Errors are formatted in standard RFC-7807 JSON.

CodeError ConstantDescription
401UNAUTHORIZEDInvalid or revoked API Key.
404SESSION_NOT_FOUNDSpecified session does not exist.
422INVALID_PHONE_NUMBERPhone is not formatted in valid E.164.
429RATE_LIMIT_EXCEEDEDToo many requests within 60s window.
503WHATSAPP_GATEWAY_DOWNMeta Cloud API or socket unreachable.
