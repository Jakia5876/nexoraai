# NEXORAAI Official Brand Assets

## Official Logo Placement
Place the official brand logo file here as:
- `assets/images/logo.png` (High-res transparent PNG)
- or `assets/images/logo.svg` (Vector format)

## Automatic Detection & Rendering
All application pages, navigation bars, authentication screens, dashboard sidebars, and admin consoles are configured to load:
`<img src=".../assets/images/logo.png" alt="NEXORAAI" class="brand-logo-img" />`

- Proportions and aspect ratios are strictly preserved (`object-fit: contain`).
- Renders crisply on dark backgrounds (`#06090B`, `#0C1114`).
- Standard brand text displays alongside: `NEXORAAI`.
