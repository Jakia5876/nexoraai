Features

Everything you need to automate customer conversations

A complete platform for WhatsApp automation, AI, leads, and business growth

Core

WhatsApp API

Full-featured REST API for sending and receiving WhatsApp messages. Supports text, media, templates, buttons, and lists. Developer-friendly with SDKs in multiple languages.

  • Send/receive all message types
  • Multi-session management
  • Webhook delivery
  • Full API documentation

AI Auto Reply

Instantly respond to customers 24/7 with intelligent AI replies trained on your business data.

AI Agents

Create multiple specialized AI agents — sales, support, lead qualification, order tracking, and more.

Unified Inbox

Manage all WhatsApp conversations in a single, organized inbox. Assign agents, add tags, and collaborate as a team.

Lead Management

Kanban-style lead pipeline. Track leads from capture to close with full activity history.

Lead Research

Research and import business leads from authorized data sources. Filter by keyword, category, and location.

Campaign Manager

Send targeted WhatsApp, email, and SMS campaigns with scheduling, rate limiting, and analytics.

Workflow Automation

Visual no-code workflow builder. Create complex automations with triggers, conditions, and multi-step actions.

Order Management

Full e-commerce order lifecycle. Create, track, update, and fulfill orders directly from WhatsApp conversations.

Real-time Analytics

Comprehensive dashboards for messages, leads, campaigns, agents, and revenue. Filter by date range.

Developer API

Full REST API with detailed documentation, multiple SDK languages, webhooks, and API key management.

Team Management

Multi-role team access. Agents, managers, and admins each with fine-grained permission controls.
